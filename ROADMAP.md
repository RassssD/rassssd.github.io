## Design reference: tommharris.github.io

Rasmus flagged this site (https://github.com/TomMHarris/tommharris.github.io) as a layout he likes, especially the research page (`research.html`) and the homepage `.about` photo+bio layout. Several ideas below have since been adopted (top nav instead of sidebar, centered column, `<details>`-based abstracts, the paper-card structure, GoatCounter, and a homepage hero modeled on Tom's `.about` section). Remaining ones — noted per bullet — are still just ideas.

What's good about it:

- **Structure per paper**: venue badge (e.g. "SSRN") → title → authors → year → a row of pill-style link buttons (Abstract, Paper, Data, Interactive Map) → optional media-coverage line → image. Consistent, scannable pattern regardless of paper type. — **Adopted** in `pages/research.md`'s `.paper` cards.
- **Abstracts as native `<details>/<summary>`**, styled as a bordered chip that expands inline — no custom JS needed. — **Adopted**, replaced the old JS accordion.
- **Overall layout**: top nav instead of a fixed sidebar; single centered column; generous whitespace; a responsive breakpoint that stacks nav and lets images go full-width. — **Adopted**: `.topnav` + centered `main` (800px) replaced `.sidenav`/`.wrapper`.
- **Homepage `.about` section**: photo + bio side by side. — **Adopted** as the homepage `.hero` (mirrored: text left, photo right, per Rasmus's preference).
- **Analytics**: GoatCounter. — **Adopted**, `goatcounter: rasmusduret` in `_config.yml`.
- **Author list with progressive disclosure**: long author lists collapse to "and 9 more authors", click to expand. — Not adopted; not needed yet (no paper here has a long author list), but worth doing if one shows up.
- **Explicit "Work in Progress" section** (title + one-line description, no abstract chip) for papers that aren't public yet. — Not adopted; still the suggested fix for the Estonia fertility paper's "very early-stage" entry (see above).
- **Clickable images**: when a figure has an interactive online version, the image itself is a link, border firming up on hover to signal it's clickable. — Not adopted; no paper here has an interactive version yet.
- **Media coverage row**: outlet name links, colored in the outlet's own brand color only on hover. — Not adopted; no press coverage to show yet.
- **Design system via CSS custom properties** (`--bg`, `--text`, etc. defined once, reused everywhere). — Not adopted; `styles.css` still uses literal hex colors throughout. Would make future re-theming easier but is a bigger refactor, not requested.

## Notes

- Site is built with Jekyll (`minima` theme) on GitHub Pages, no custom CI.
- Nav is a top bar in `_layouts/default.html` (name, links, socials — no photo; hardcoded, not data-driven).
- Content pages are Markdown in `pages/`; Jekyll auto-converts `.md` → `.html`, which is why links like `/pages/research.html` work despite the source being `research.md`.
- **Caching gotcha**: twice during the header/homepage rework, a change that looked "not applied" after a push turned out to already be live — GitHub Pages rebuilds take a minute or two, and browsers cache aggressively. Before assuming a push didn't take effect, `curl` the live URL directly (or its raw file on `raw.githubusercontent.com`) and check the actual HTML/CSS rather than trusting a screenshot alone; a hard refresh (Ctrl+Shift+R) or incognito window usually resolves it on the viewer's side.
